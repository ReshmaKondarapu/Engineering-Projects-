# Engineering Projects Portfolio

Welcome to my hardware and embedded systems portfolio. This repository contains complete design files, source code, schematics, and documentation for engineering projects.

---

## 📁 Projects Overview

### 1. [Crypto Processor for Visual Data Security](./Project-1-Crypto-Processor)
* **Tech Stack:** Verilog HDL, Xilinx Vivado, Xilinx Artix-7 FPGA
* **Description:** Hybrid cryptographic system combining AES-256 for real-time pixel stream encryption and RSA-4096 for secure key exchange.

### 2. [64-bit RISC-V Processor Core](./Project-2-64-bit-RISC-V)
* **Tech Stack:** Verilog HDL, GTKWave, ModelSim / Vivado
* **Description:** Implementation of a 64-bit RISC-V CPU architecture with full instruction fetch, decode, execute, memory, and writeback pipeline stages.

### 3. [Drowsiness Detection & Accident Prevention System](./Project-3-Drowsiness-Accident-Prevention)
* **Tech Stack:** NodeMCU ESP8266, C++, I2C, Embedded Systems
* **Description:** Real-time driver vigilance system using IR eye-blink sensors to trigger safety alerts and motor cut-off mechanisms.
